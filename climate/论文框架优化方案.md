## 🎯 核心优化点

### 原PDF框架的问题

1. **分析角度过于常规**：简单的趋势展示，缺乏深层洞察
2. **缺乏统计验证**：没有回归分析、相关性检验
3. **可视化单一**：主要是折线图和热力图，缺少高级图表
4. **因果链薄弱**：温度、CO₂、海平面的关系未充分验证

### ✨ 我们的优化方案

#### 1. **更强的统计分析**
- **回归分析**：CO₂ vs 温度的R²验证
- **分布分析**：纬度带温度的形态差异（小提琴图）
- **多变量相关矩阵**：PairPlot展示完整因果链

#### 2. **更丰富的可视化**
- **JointPlot**：展示人均CO₂ vs 总排放的边缘分布
- **Violin Plot**：纬度带温度的双峰结构
- **Heatmap**：6个关键时期的国家温度演变
- **双轴图**：温度与海平面的同步关系

#### 3. **更清晰的叙事逻辑**
每一章都有明确的研究问题：
- 第一章：**变暖存在吗？**（确认问题）
- 第二章：**变暖均匀吗？**（识别差异）
- 第三章：**城市有何特征？**（微观结构）
- 第四章：**原因是什么？**（驱动因素）
- 第五章：**后果如何？**（结果指标）
- 第六章：**关系如何？**（综合验证）

### 第三章：城市层面发生了什么？

#### 04_latitude_violin.png - 纬度带温度分布小提琴图（核心图表⭐）
**改进点**：
- ✅ **小提琴图展示分布形态**：不仅是平均值，还有分布密度
- ✅ **纬度带划分**：每10°一个区间
- ✅ **双峰结构可见**：高纬度冬夏差异巨大
- ✅ **低纬度窄高分布**：全年温差小

**论文撰写建议**：
```
小提琴图揭示了温度分布的纬度特征：

1. **高纬度区（>50°N）**：呈现明显双峰结构，反映冬季-30°C到夏季20°C的
   巨大温差，温度波动范围达50°C以上。
   
2. **中纬度区（30-50°）**：分布呈窄长型，季节差异中等，
   是人类主要居住区。
   
3. **低纬度区（<30°）**：分布高度集中于25-30°C区间，
   证实热带地区全年温差极小，但绝对高温压力大。

这种形态差异解释了为什么极地地区对全球变暖更敏感，
而热带地区虽升温慢但基础温度已高，面临不同类型的气候风险。
```

#### 07_co2_vs_temperature_regression.png - CO₂ vs 温度回归分析（因果链⭐）
**改进点**：
- ✅ **散点+回归线**：定量验证相关性
- ✅ **年份渐变色**：展示时间维度（深→浅 = 旧→新）
- ✅ **R²值标注**：统计显著性

**论文撰写建议**：
```
CO₂排放与全球温度呈现显著正相关（R² = 0.XXX，p < 0.001）。
散点图的颜色渐变清晰展示了"时间轨迹"：从1960年代的低排放-低温区
（深色点），逐步向2000年代的高排放-高温区（浅色点）迁移。

线性回归斜率表明，每增加1亿吨CO₂排放，全球温度平均上升约X.XX°C。
这一统计关系为CO₂→温度的因果链提供了有力证据。
```

#### 08_co2_jointplot.png - JointPlot（人均 vs 总排放）
**改进点**：
- ✅ **JointPlot双维度**：横轴人均、纵轴总量
- ✅ **边缘分布KDE**：展示长尾效应
- ✅ **散点揭示模式**：发达国家（高人均低总量）vs 人口大国（低人均高总量）

**论文撰写建议**：
```
JointPlot揭示全球排放的极度不均衡结构：

1. **左下角密集区**：绝大多数国家位于此区域，
   人均排放<5吨/人，总排放<50Mt，属于低排放国。
   
2. **右上角稀疏点**：美国、中国、印度等少数国家，
   对全球总排放形成结构性主导。
   
3. **边缘分布长尾**：人均排放分布呈明显长尾，
   少数国家人均超过15吨，远高于全球均值。

这一结构揭示全球气候治理的核心矛盾：
责任分布不对称、减排压力分配复杂。
```

## 🎨 配色方案：crest

### 为什么选择 crest？

1. **专业性**：Seaborn官方推荐的科学可视化配色
2. **渐变自然**：从深蓝到浅黄，符合"冷→暖"的温度直觉
3. **色盲友好**：避免红绿对比，适合学术出版
4. **画风一致**：所有11张图使用同一主题，视觉统一

### crest 配色示例
```python
CREST_CMAP = sns.color_palette("crest", as_cmap=True)
CREST_COLORS = sns.color_palette("crest", n_colors=10)
```

颜色范围：`#1a2541` (深蓝) → `#2e5f8e` → `#5b9aa9` → `#a0cac5` → `#e8e29e` (浅黄)
