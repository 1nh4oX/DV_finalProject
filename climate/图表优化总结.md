## ✅ 修复的问题

### 1. **图02 - 国家温度热力图**

**❌ 原问题**：
- 颜色对比度不够，看起来都是一个颜色
- 固定的 vmin/vmax 范围(-10, 30)不合理

**✅ 修复方案**：
```python
# 使用数据实际范围
data_min = heatmap_df.min().min()
data_max = heatmap_df.max().max()

sns.heatmap(..., vmin=data_min, vmax=data_max, robust=True)
```

**效果**：颜色对比度明显提升，能清晰看出不同国家的温度差异

---

### 2. **图05 - CO2排放分布**

**❌ 原问题**：
- 组合图（scatter + hist + kde）太复杂，看不清重点
- 图表元素重叠，信息混乱

**✅ 修复方案**：
- 改用简洁的 JointPlot
- 只保留散点 + 边缘直方图
- 清晰展示"人均 vs 总量"的双维度

**效果**：一目了然，清晰展示排放结构

---

### 3. **图06 - CO2时间序列**

**❌ 原问题**：
- 条件KDE归一化有问题
- 所有国家的颜色几乎一致（common_norm=False 没起作用）
- 看不出各国趋势差异

**✅ 修复方案**：
- 改用经典的多折线图
- 每个国家一条线，使用 viridis 渐变色
- 清晰展示各国排放轨迹

**效果**：能清楚看出中国、美国等主要排放国的趋势变化

---

### 4. **字体问题**

**❌ 原问题**：
- CO₂ 的下标"₂"无法显示
- 警告：`Glyph 8322 (\N{SUBSCRIPT TWO}) missing from font(s)`

**✅ 修复方案**：
- 使用 "CO" 替代 "CO₂"（中文环境下更简洁）

## 📐 设计原则（参考 Seaborn 官方）

### 1. **合理的图表尺寸**
- 单图：`figsize=(12, 6)` 或 `(14, 7)`
- 方形图：`figsize=(10, 10)`
- JointPlot：`height=8 or 9`
- PairPlot：`height=3`

### 2. **协调的配色方案**
- **主配色**：viridis（渐变，区分度高）
- **暖色调**：magma、rocket（温度相关）
- **冷色调**：mako（数据密度）
- **单色亮点**：#4CB391（官方推荐）

### 3. **适当的留白与网格**
```python
sns.set_theme(style="ticks", context="talk")
ax.grid(True, alpha=0.25)
sns.despine()  # 去掉上右边框
plt.tight_layout()
```

### 4. **清晰的标签与图例**
- 标题：`fontsize=14, weight='bold'`
- 坐标轴：`fontsize=12, weight='medium'`
- 图例：`fontsize=10, frameon=True, framealpha=0.9`
